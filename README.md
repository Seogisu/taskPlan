# SOXL "−15% 매수 / +10% 익절" 백테스트

SOXL(Direxion Daily Semiconductor Bull 3x)을 **상장(2010-03-11) 이후 하루에 15% 이상
하락한 날 종가에 매수**하고, **+10% 도달 시 익절**하는 전략의 백테스트입니다.
요청대로 **세금·수수료는 제외**(gross)했습니다.

## 전략 정의
| 항목 | 규칙 |
|---|---|
| 유니버스 | SOXL, 상장일 2010-03-11 부터 |
| 진입 신호 | 전일 종가 대비 당일 종가 수익률 ≤ **−15%** |
| 진입 | 해당일 **종가** 매수 |
| 청산 | 진입가 **+10%** 지정가 익절 (이후 거래일 고가가 entry×1.10 터치 시 체결) |
| 포지션 | 한 번에 1개, 전액 재투자(복리) |
| 비용 | 수수료·세금 0 (요청), 배당도 제외 |

## 데이터
분할(split) 조정된 일봉 OHLC를 공개 GitHub CSV 두 개에서 이어붙였습니다.
두 소스의 분할조정 종가는 겹치는 1,156 거래일에서 **오차 0.0000%**로 일치하여
접합 신뢰성을 검증했습니다.

- 2010-03-11 ~ 2019-05-16: `mohaoqing/Simple-Trader`
- 2019-05-17 ~ 2026-05-15: `kinryukii/us-tech-quant-v19` (데이터 최신일 = 2026-05-15)

> 배당조정(Adj Close)이 아닌 분할조정 종가/고가를 사용합니다. 전략이 실제 체결가로
> 매매하고, 배당은 수수료·세금과 함께 제외 대상이기 때문입니다.

## 결과 (복리, 1포지션 운용)

```
데이터 구간      : 2010-03-11 → 2026-05-15 (4,071 거래일)
−15% 하락일(전체): 39 일
실제 진입한 트레이드: 18 (나머지는 보유중이라 스킵)
+10% 익절 달성    : 18 / 18
보유기간          : 최소 1일, 중앙값 3일, 최대 374일, 평균 34.8 거래일
─────────────────────────────────────────────
누적 수익률       : ×5.56  ( +456% )
전략 CAGR (~16.2y): +11.2%
단순 보유(Buy&Hold): +24,757%  (×248)
```

### 핵심 해석
- **+10% 목표는 역사적으로 거의 항상 달성**되었습니다. 39번의 −15% 급락일을 각각
  독립 트레이드로 봤을 때 **39/39 전부** 이후 +10% 반등을 달성(평균 보유 29 거래일).
  3배 레버리지 ETF라 급락 후 반등이 빠르기 때문입니다.
- 그러나 **"1포지션·전액" 규칙 때문에 39번 중 18번만 진입**했습니다. 특히
  **2024-07-17 진입 포지션이 +10% 회복까지 374 거래일(2026-01-13)** 걸리면서,
  그 사이의 최대 매수 기회였던 **2025년 4월 관세 폭락(-29.8%, -23.5%, -24.6%)을 통째로 놓쳤습니다.**
- 결과적으로 +10% 익절로 상승을 매번 잘라먹고 대부분 현금으로 대기하므로,
  장기 폭등주인 SOXL을 **단순 보유(+24,757%)에 크게 못 미칩니다(+456%).**

## 최근 7년 (2019-06-21 ~ 2026-05-15)

```
−15% 하락일(전체): 32 일
실제 진입한 트레이드: 13 (나머지는 보유중이라 스킵)
+10% 익절 달성    : 13 / 13
보유기간          : 최소 1일, 중앙값 2일, 최대 374일, 평균 44.6 거래일
─────────────────────────────────────────────
누적 수익률       : ×3.45  ( +245% )
전략 CAGR (~6.9y): +19.7%
단순 보유(Buy&Hold): +1,733%  (×18.3)
```

전체 구간과 동일한 패턴입니다. 13번 모두 +10% 달성했지만, **2024-07-17 진입분이
374 거래일(2026-01-13)** 묶이면서 2025년 4월 관세 폭락(−29.8%, −23.5%, −24.6%) 등
2024-08~2025-10의 모든 급락 기회를 스킵했고, 결국 단순 보유(+1,733%)에 크게 못 미칩니다.

## 변형: 종가 기준 10% 트레일링 스탑 (최근 7년)

매수 조건은 동일(−15% 종가 매수). 매도만 **고정 +10% 익절 → 종가 기준 10% 트레일링
스탑**으로 변경: 매수 후 **종가가 신고가를 갱신할 때마다 기준점을 그 상승 종가로
재조정**하고, 종가가 그 고점 대비 **−10%** 떨어지면 그날 **종가에 매도**.

```
데이터 구간      : 2019-06-21 → 2026-05-15 (1,736 거래일)
−15% 하락일/진입 : 32 / 32   (빨리 청산돼 한 건도 스킵 없음)
승률             : 11 / 32  (34%)
트레이드 평균    : −2.32%   (최고 +40.7%, 최저 −30.4%)
보유기간         : 최소 1일, 중앙값 4일, 최대 19일, 평균 6.2 거래일
─────────────────────────────────────────────
누적 수익률      : ×0.30  ( −70% )
전략 CAGR        : −15.9%
단순 보유(Buy&Hold): +1,733%  (×18.3)
```

### 왜 +245% → −70% 로 뒤집히나
- 트레일링 스탑은 청산이 빨라(중앙값 4일) **32번 신호를 모두 진입**하지만, SOXL의
  −15% 급락일은 **다음날도 더 빠지는 경우가 많아**(모멘텀) 10% 트레일에 **손절로
  털리기 일쑤**입니다. 3배 레버리지가 손실을 증폭합니다.
  - 예: 2020-03 폭락 연쇄(−1.1%, −30.4%, −21.8%, −18.5% …), 2024-07~09 연속 손절.
- 즉 앞선 고정 +10% 익절이 이겼던 건 **"절대 손절하지 않고 반등까지 기다렸기"** 때문이고
  (대신 한 포지션이 374일까지 묶임), 손절 규칙을 넣는 순간 **승률 34%·평균 −2.3%**로
  무너집니다. 같은 진입 신호라도 **출구 규칙이 결과를 지배**합니다.

> 참고: 트레일 기준점을 "진입가"가 아니라 "진입일 종가"에서 시작해 신고가마다
> 올립니다. 진입 직후 반등 없이 빠지면 사실상 entry 대비 −10% 손절이 됩니다.
